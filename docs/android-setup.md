# 安卓方案搭建

安卓上这件事比 iOS 简单得多：系统直接提供了读通知和往通知里回复的
官方 API，不需要 root，也不需要碰微信本身。

## 两种实现，主次分明

| | 主力：通知直接回复 | 兜底：无障碍操作界面 |
|---|---|---|
| 文件 | `WeChatNotificationService.kt` | `WeChatAccessibilityService.kt` |
| 原理 | 微信通知自带「回复」按钮（RemoteInput），往里灌文字并触发 | 读屏幕控件树，找输入框打字点发送 |
| 需要权限 | 通知使用权 | 无障碍权限（**权限很大**） |
| 微信要在前台吗 | ❌ 不需要 | ✅ 需要停在聊天页 |
| 消息完整度 | 通知可能截断长消息 | 完整 |
| 免打扰会话 | ❌ 收不到 | ✅ 能处理 |

**默认只开主力方案就够了。** 只有当你遇到「通知没有回复按钮」或
「会话开了免打扰」时，才需要额外打开无障碍。

## 一、跑起规则服务

在电脑上（和手机同一局域网）：

```bash
pip install -r requirements.txt

export WXAUTO_CONFIG=core/config.example.yaml
export WXAUTO_TOKEN=$(openssl rand -hex 16)   # 记下这个值
uvicorn server.app:app --host 0.0.0.0 --port 8848
```

查一下电脑的局域网 IP（`ip addr` 或 `ifconfig`），比如 `192.168.1.10`。

## 二、编译安装 App

```bash
cd android
./gradlew assembleDebug
adb install app/build/outputs/apk/debug/app-debug.apk
```

如果没有实体机，用模拟器时规则服务地址填 `http://10.0.2.2:8848`
（模拟器里 `10.0.2.2` 指向宿主机）。

## 三、配置和授权

打开「微信自动回复」App：

1. 填规则服务地址：`http://192.168.1.10:8848`
2. 填 token：第一步生成的那个值
3. 点「保存」
4. 点「① 授予通知使用权」→ 在系统页面里找到本应用并打开
5. （可选）点「② 授予无障碍权限」

> 改完地址或 token 后，需要到「通知使用权」里**关掉再打开**本应用，
> 服务才会重新读配置。

## 四、验证

给自己的微信发条消息（用另一个号，或让朋友发），然后看日志：

```bash
adb logcat -s WeChatNotifService:I ReplyEngineClient:W
```

正常应该看到：

```
I WeChatNotifService: 已回复「小王」：在的，我这会儿在忙，稍后回你（自动回复）
```

或者被规则挡下：

```
I WeChatNotifService: 不回复「小王」：该会话冷却中，还剩 1523s
```

## 五、常见问题

**日志里什么都没有**
通知使用权没给，或者给了之后没重启服务。到系统设置里关掉再打开一次。

**「通知没有回复入口，交给无障碍方案兜底」**
你的 ROM 剥掉了 RemoteInput（小米、部分定制系统上出现过）。
开无障碍方案，或者去微信通知设置里确认「显示消息详情」是打开的。

**回复发出去了但对方没收到**
检查微信是不是被系统「电池优化」杀了后台。把微信和本 App 都加进
省电白名单。

**规则服务不可达**
手机和电脑不在同一网段，或者电脑防火墙挡了 8848。
先在手机浏览器里访问 `http://192.168.1.10:8848/health` 试试。

## 六、安全提醒

这个 App 拿到通知使用权后，**能读到你手机上所有 App 的通知**。
代码里只处理 `com.tencent.mm` 一个包，也不落盘存任何消息内容
（只往你自己的规则服务发一次），但这是靠代码自觉，不是靠系统限制。

所以：**只装你自己编译的版本**。
